## Aperçu

Ce document décrit les jetons de couleur (« colour tokens ») utilisés dans l'interface
utilisateur de Holos, conformément au Système de conception du gouvernement du Canada
(GC Design System). Les jetons couvrent les couleurs de texte, les liens, les arrière-plans,
les bordures, les états (danger, désactivé, focus), ainsi que les jetons de couleur de base
(échelle de gris, bleus, rouges, etc.).
